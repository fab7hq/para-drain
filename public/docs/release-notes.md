# ParaDrain 0.1 — final version

ParaDrain 0.1 (package 0.1.0) is the final product design presented by this repository and website.

## Product

Two identical, interchangeable directional baskets share a fixed frame. Each basket has a collection floor, side walls and slotted top. A shared front retainer and two keeper pins secure the collection opening for lifting. Flared guides, station bolts and a linked manual pusher support removal, transfer and reinsertion.

Both baskets carry **PARADRAIN UPSTREAM**, centered on the solid top handle grip. Both positions require the same upstream orientation.
